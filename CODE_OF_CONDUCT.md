# Code of Conduct

## Our standards

We want Aegis SSH to be a practical, respectful, and security-conscious open source project.

Examples of expected behavior include:

- discussing technical tradeoffs with evidence and respect;
- giving actionable feedback without personal attacks;
- respecting privacy, infrastructure boundaries, and responsible disclosure;
- helping contributors correct mistakes without public humiliation;
- accepting maintainers' decisions about project scope and security boundaries.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, publishing private information, or using project channels to expose credentials or infrastructure details.

## Scope

This code applies to repository issues, pull requests, discussions, reviews, and other public or private project interactions. It also applies when someone officially represents the project elsewhere.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may temporarily or permanently restrict participation. Enforcement decisions should be proportionate, documented privately where practical, and focused on protecting project participants.

## Reporting

Do not publish sensitive conduct reports or personal information in a public issue. Contact the repository owner through a private GitHub channel. If no private channel is available, open a minimal issue asking for private contact without including incident details.

Security vulnerabilities and leaked technical secrets must follow [SECURITY.md](SECURITY.md).
